# Sitcomdle

A Wordle-inspired guessing game where players identify sitcom characters using clues and logical deduction.
Play at `https://sitcomdle.vercel.app/`.
## Features

- Daily character guessing challenge
- Unlimited gameplay mode
- Attribute-based hints and feedback
- Characters from popular sitcoms
- Responsive interface

## Tech Stack

Next.js, React, TypeScript, Tailwind CSS

## Getting Started

```bash
git clone <repository-url>
cd sitcomdle
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.


## How to Play

Guess the mystery sitcom character within six attempts. Each guess provides feedback on character attributes to help narrow down the correct answer.
